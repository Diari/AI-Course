# AI Course

Workshop materials for non-technical professionals — Product Managers, Designers, Marketers, and Business leaders — who want to use AI effectively in their day-to-day work.

These accompany live workshops I run on AI workflows and Claude Cowork.

## What's Included

### [The Complete Guide to Claude Cowork](./claude-cowork-comprehensive-guide.md)

A comprehensive reference for getting maximum value from Claude Cowork — Anthropic's agentic desktop tool for knowledge workers. Covers setup, context architecture, skills, plugins, connectors, scheduled tasks, safety, and real-world use cases with prompt templates.

### [Workshop Presentation](./session-b-build-your-ai-system.pptx)

Slides from the live workshop covering prompt patterns, tool selection, and building autonomous AI workflows with Claude Cowork.
